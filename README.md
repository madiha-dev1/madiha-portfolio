# Madiha Portfolio

React + Vite + Tailwind CSS portfolio based on the supplied dark neon reference design.

## Run
```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build
```bash
npm run build
```

## Main files
- `src/App.jsx` — all portfolio sections and UI
- `src/index.css` — global styling/animations
- `src/assets/` — supplied portrait assets
- `public/` — project preview placeholders

Replace the placeholder email, social links, project data and project preview images with your real information.
